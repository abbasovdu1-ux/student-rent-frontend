# 🏠 StudentRent – Frontend

**StudentRent** ist eine moderne Webplattform für die Suche und Vermittlung von studentischem Wohnraum in Berlin.

Das Projekt entsteht im Rahmen eines universitären Gruppenprojekts im Bereich Webtechnologien.

## 💡 Projektidee

Die Wohnungssuche soll einfacher, schneller und interaktiver werden.

Statt sich durch lange Listen von Wohnungsanzeigen zu klicken, setzt StudentRent auf ein **Swipe-basiertes Konzept, inspiriert von TikTok**.

Nutzer können durch verschiedene Wohnungs- und WG-Angebote scrollen und bei Interesse direkt die Detailansicht einer Anzeige öffnen.

So verbindet StudentRent die intuitive Bedienung moderner Social-Media-Plattformen mit der klassischen Wohnungssuche.

## ✨ Fertige Funktionen

- 📱 **Swipe-Feed:** Wohnungsangebote in einem vertikal scrollbaren Feed entdecken
- 🏡 **Detailansicht:** Ausführliche Informationen zu Wohnungen und WG-Zimmern anzeigen
- 📝 **Anzeigen erstellen:** Eigene Wohnungsangebote veröffentlichen
- 🔎 **Wohnungssuche:** Passende Angebote für Studierende entdecken
- 💻 **Responsive Design:** Benutzerfreundliche Darstellung auf unterschiedlichen Geräten

### 🚀 Zukünftige Erweiterungen

- ⭐ **Premium-Anzeigen:** Wohnungsanzeigen gegen Bezahlung hervorheben
- 📈 **Mehr Sichtbarkeit:** Höhere Reichweite für ausgewählte Anzeigen
- 🎯 **Personalisierte Empfehlungen:** Passende Wohnungsangebote anhand individueller Präferenzen anzeigen

| Bereich | Technologien |

| Frontend | Vue 3, JavaScript, HTML, CSS |

| Versionsverwaltung | Git & GitHub |

## 🏗️ Architektur

StudentRent besteht aus zwei getrennten Anwendungen:

**Frontend (Vue 3)**  
Verantwortlich für die Benutzeroberfläche, die Darstellung der Wohnungsangebote und die Interaktion mit den Nutzern.

**Backend (Spring Boot)**  
Verantwortlich für die serverseitige Verarbeitung, Datenverwaltung und Bereitstellung der REST API.

🔗 **[Zum Backend-Repository](https://github.com/abbasovdu1-ux/student-rent-project)**

## 💻 Lokale Installation

### Voraussetzungen

- Node.js
- npm

### Repository klonen

```bash
git clone https://github.com/abbasovdu1-ux/student-rent-frontend.git
cd student-rent-frontend
```

### Abhängigkeiten installieren

```bash
npm install
```

### Entwicklungsserver starten

```bash
npm run dev
```

Für bestimmte Funktionen muss zusätzlich das Backend gestartet werden.
