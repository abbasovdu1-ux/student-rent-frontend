# StudentRent Frontend

StudentRent ist eine Webplattform für die Suche und Vermittlung von studentischem Wohnraum in Berlin. Das Projekt entsteht im Rahmen eines universitären Gruppenprojekts im Bereich Webtechnologien.

## Projektidee

Die Wohnungssuche soll einfacher, schneller und interaktiver werden. Statt sich durch lange Listen von Anzeigen zu klicken, setzt StudentRent auf ein Swipe-basiertes Konzept, inspiriert von TikTok. Nutzer scrollen durch Wohnungs- und WG-Angebote und öffnen bei Interesse direkt die Detailansicht einer Anzeige.

## Funktionen

- **Swipe-Feed:** Wohnungsangebote in einem vertikal scrollbaren Feed entdecken
- **Detailansicht:** Ausführliche Informationen zu Wohnungen und WG-Zimmern
- **Anzeigen erstellen:** Eigene Wohnungsangebote veröffentlichen
- **Responsive Design:** Darstellung auf unterschiedlichen Geräten

### Geplante Erweiterungen

- **Premium-Anzeigen:** Anzeigen gegen Bezahlung hervorheben und ihre Reichweite erhöhen
- **Personalisierte Empfehlungen:** Angebote anhand individueller Präferenzen anzeigen

## Tech Stack

| Bereich | Technologien |
|---|---|
| Frontend | Vue 3, JavaScript, HTML, CSS |
| Build Tool | Vite |
| Backend | Java 21, Spring Boot |
| Datenbank | PostgreSQL |
| Kommunikation | REST API |

## Architektur

StudentRent besteht aus zwei getrennten Anwendungen:

- **Frontend (Vue 3):** Benutzeroberfläche, Darstellung der Angebote und Interaktion mit den Nutzern
- **Backend (Spring Boot):** Serverseitige Verarbeitung, Datenverwaltung und Bereitstellung der REST API
